## About These Tutorials

These tutorials use [asciinema](https://asciinema.org/) for terminal recordings.
You can:

- **Watch** the recordings embedded in the docs
- **Copy commands** directly from the player
- **Re-record** yourself using the provided scripts

## Recording Your Own

Install asciinema:

```bash
pip install asciinema
```

Record a session:

```bash
asciinema rec tutorial.cast
```

Upload to share:

```bash
asciinema upload tutorial.cast
```
